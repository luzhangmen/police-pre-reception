# 3D / 全景（VR）地图概念说明

## 用户要什么？

在二维地图标点之外，**看一眼事发地长什么样**（街景 / 360° 全景）。作业或演示里通常只需 **一个地点的概念验证**，不必覆盖全国街景。

## 国内现实情况（广州大学城）

| 方案 | 广州大学城覆盖 | 是否适合「当地全景」 | 备注 |
|------|----------------|----------------------|------|
| **Google 街景** | 很少 / 常无 | 不推荐作为主方案 | 国内覆盖稀疏，需 API Key，且服务不稳定 |
| **高德 / 百度 街景·全景** | 部分道路有 | **正式产品首选** | 需企业 Key、合规与配额；华工大学城外围商业街相对更有 |
| **Mapillary / KartaView** | 零散众包 | 可作补充 | 开源社区图，大学城不一定有连续街景 |
| **自有 360° 照片 + 开源查看器** | 完全可控 | **课程概念演示首选** | 手机「全景」模式拍一张，用 Pannellum 嵌入 |

结论：**可以只做广州大学城一个点的 VR 概念**；演示上最稳的是 **一张 360° 实拍图 + Pannellum（MIT 开源）**，商业环境再对接高德/百度全景 API。

## 本仓库 Demo 怎么做

`demo.html` 底部 **「全景概念 (VR)」** 区域：

1. **Pannellum** 内嵌 360° 查看 — **可以像 VR 一样浏览**（见下）。
2. **Mapillary 嵌入** — 若该经纬度附近有众包街景则显示（可能为空，属正常）。
3. **外链** — 一键在高德 / Google 地图中打开同一坐标（Google 可能提示无街景）。

### 在 Demo 里怎么「像 VR 一样」操作？

| 操作 | 效果 |
|------|------|
| 在全景画面里 **按住鼠标拖动** | 环视上下左右（最常用） |
| **滚轮** | 放大 / 缩小视野 |
| 点 **「全屏沉浸浏览」** 或 **双击画面** | 全屏，更接近 VR |
| **手机**：点「开启陀螺仪环视」 | 转动手机，画面跟着转（需浏览器授权） |
| 画面右下角 **+ / − / 全屏** 按钮 | Pannellum 自带控件 |

说明：这是 **360° 全景环视**（网页里常见），不是 VR 头显里的立体 3D；若要头显模式需额外做 WebXR，作业概念演示一般不需要。

### 华工本地实拍（已接入）

仓库已包含 `frontend/public/panoramas/scut-north-teaching.jpg`，Demo 默认加载该文件。

追加其他地点时，放入 `scut-dorm-parking.jpg`、`scut-xiaobei-street.jpg` 即可；未放入前，相关案例会共用北区实拍图。

### 环境变量（完整产品，可选）

```env
AMAP_API_KEY=...      # 地理编码 + 二维地图
AMAP_WEB_KEY=...      # 高德 JS 含部分街景能力（视开通产品而定）
GOOGLE_MAPS_API_KEY=...  # 仅在有街景覆盖且可访问时使用
```

## 与接警业务的关系

全景适合：**帮助接警员建立空间感**（宿舍楼下、商业街口），不能替代笔录与坐标。Demo 中已标注「概念演示」。
