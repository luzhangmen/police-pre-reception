## 一、我完成了什么

本模块将后端 pipeline 输出的 **`CaseState`（结构化案件状态）** 自动生成为警方可查看、可打印归档的 **《校园警务预受理信息单》**（`.docx`）。

核心能力：

1. **HTTP 接口**：接收完整 `CaseState`，生成 Word 并返回下载链接。  
2. **程序化排版**：13 个固定章节 + 元信息表 + 高风险预警横幅（非简单填空模板）。  
3. **叙述润色**：对群众口语输入去废话（嗯、那个等），并按场景合成规范的「事件经过」。  
4. **结构化展示**：自动填入 slots、缺失字段、证据、知识库建议、警方摘要、系统追问等。  
5. **答辩样例**：提供 4 类场景（财物遗失 / 诈骗 / 人身威胁 / 宿舍冲突）一键生成脚本。  
6. **L2 口语案例库**：新增冗长口语测试用例，供评测与答辩对比使用。

> **说明**：当前交付为 **Word（.docx）**；PDF 导出在计划中列为后续扩展，接口 `format` 字段已预留。

## 三、系统怎么串起来（给组长看架构）

```text
用户口语 / 文本输入
        ↓
POST /api/v1/reason  （或 陈誉的多轮 POST /api/v1/dialogue/turn）
        ↓
    CaseState（JSON）
        ↓
POST /api/v1/documents/pre-acceptance
        ↓
  narrative_polish（清洗 + 合成叙述）
  document_content（组装 13 节内容）
  document_styling（Word 排版）
        ↓
  backend/generated/documents/pre_acceptance_xxx.docx
        ↓
GET /api/v1/documents/download/{filename}  →  浏览器/前端下载
```

**输入约定**：文档接口的请求体 = **`CaseState` 全量 JSON**，与 `/api/v1/reason` 的响应结构一致，可直接透传，无需额外字段。

## 四、如何使用

### 4.1 环境准备

```bash
cd backend
python -m pip install -r requirements.txt
```

需已安装：`python-docx`、`jinja2`（见 `requirements.txt`）。

### 4.2 启动后端

```bash
cd backend
# Windows PowerShell 建议设置 PYTHONPATH
$env:PYTHONPATH = (Get-Location).Path
uvicorn app.main:app --reload --host 127.0.0.1 --port 8000
```

浏览器打开 Swagger：**http://127.0.0.1:8000/docs**

### 4.3 方式 A：Swagger 联调（推荐组长验收）

1. 先调 **`POST /api/v1/reason`**，输入报案文本，得到 `CaseState`。  
2. 复制整个响应 JSON。  
3. 调 **`POST /api/v1/documents/pre-acceptance`**，将 JSON 作为请求体粘贴提交。  
4. 响应示例：

```json
{
  "case_id": "demo-case",
  "filename": "pre_acceptance_demo-case_20260530T120000.docx",
  "file_path": "generated/documents/pre_acceptance_demo-case_20260530T120000.docx",
  "download_url": "/api/v1/documents/download/pre_acceptance_demo-case_20260530T120000.docx",
  "generated_at": "2026-05-30T12:00:00+00:00",
  "format": "docx",
  "metadata": {
    "document_version": "2.0",
    "narrative_preview": "报案人反映，于……",
    "cleaned_user_text_preview": "警官你好，我……",
    "high_risk_flags": ["仍在转账"],
    "missing_field_count": 2,
    "completeness_percent": 58,
    "section_count": 13
  }
}
```

5. 浏览器访问：`http://127.0.0.1:8000` + `download_url`，即可下载 Word。

### 4.4 方式 B：一键生成答辩样例（无需 LLM Key）

```bash
cd backend
$env:PYTHONPATH = (Get-Location).Path   # PowerShell
python scripts/generate_all_showcase_documents.py
```

生成结果目录：

```text
backend/generated/documents/showcase/
├── pre_acceptance_showcase-loss-library-2026_*.docx      # 财物遗失
├── pre_acceptance_showcase-fraud-xianyu-2026_*.docx        # 电信诈骗
├── pre_acceptance_showcase-threat-dormgate-2026_*.docx     # 人身威胁
└── pre_acceptance_showcase-dorm-noise-2026_*.docx          # 宿舍冲突
```

用 Microsoft Word 或 WPS 直接打开即可查看排版效果。

### 4.5 方式 C：curl 示例

```bash
# 1. 先推理（需配置 .env 中 LLM_API_KEY）
curl -X POST http://127.0.0.1:8000/api/v1/reason \
  -H "Content-Type: application/json" \
  -d "{\"text\": \"我在图书馆丢了手机，是黑色iPhone\"}"

# 2. 将上一步返回的 JSON 保存为 case.json 后生成文档
curl -X POST http://127.0.0.1:8000/api/v1/documents/pre-acceptance \
  -H "Content-Type: application/json" \
  -d @case.json

# 3. 按返回的 download_url 下载
curl -O http://127.0.0.1:8000/api/v1/documents/download/pre_acceptance_xxx.docx
```

### 4.6 运行自动化测试

```bash
cd backend
$env:PYTHONPATH = (Get-Location).Path
python -m pytest tests/test_document_generator.py tests/test_narrative_polish.py -q
```

## 五、生成的 Word 里有什么（13 节）

| 序号 | 章节 | 数据来源 |
|------|------|----------|
| — | 元信息表 | case_id、报案人、类型、风险、完整度、情绪、系统建议、时间地点 |
| — | 高风险横幅 | `risk_level=high` / `handoff_human` / 高风险 slots |
| 一 | 报案原话（去口语化） | `user_text` 经清洗 |
| 二 | 事件经过（结构化合成） | slots + 场景规则合成 |
| 三 | 关键事实清单 | `key_facts` |
| 四 | 已抽取结构化字段 | `slots`（表头已展示字段会去重） |
| 五 | 高风险标识 | schema 高风险字段为「是」的项 |
| 六 | 待补充信息 | `missing_fields` |
| 七 | 地理位置与地图 | `extracted_addresses`、`map_locations` |
| 八 | 证据材料 | `evidence_checklist` / `slots.evidence` |
| 九 | 知识库处置建议 | `knowledge_snippets`（何达煜 RAG 接入后同字段） |
| 十 | 警方摘要 | `police_summary` |
| 十一 | 建议下一步 | `suggested_next_steps` |
| 十二 | 系统建议追问 | `next_question`（陈誉多轮接口同源） |
| 十三 | 民警备注区 | 留空横线供手写 |

页脚含「系统辅助生成、需民警复核」免责声明。

## 八、常见问题

**Q：生成目录里找不到文件？**  
A：文件在 `backend/generated/documents/`，该目录被 gitignore，需本地运行接口或脚本后才会出现。

**Q：必须先调 reason 吗？**  
A：生产联调建议先 `reason` 再生成文档；答辩演示可直接运行 `generate_all_showcase_documents.py`。

**Q：文档内容会随 pipeline 变化吗？**  
A：会。文档完全由当次 `CaseState` 决定；slots 越完整，信息单越充实。

**Q：谁维护案例库？**  
A：L2 口语案例在 `demo_cases_colloquial.json`；与主库 `demo_cases.json` 互补，评测口径可与瞿逸凡对齐。
